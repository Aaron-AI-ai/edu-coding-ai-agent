# M9 실습 과제 2 — 종목 검색 API

상단 검색창(`/ 를 눌러 검색하세요`)에 입력하면 종목 목록이 뜨게 만든다.
화면(`edu-stock-chart-ui`)과 데이터(`data.sql`)는 준비되어 있다. **Spring Boot API 만 구현한다.**

## 지금 상태

- 화면은 입력할 때마다 아래처럼 호출한다. API 가 없어서 404 → 검색창 아래에 `검색 기능 준비 중` 이 뜬다.
  ```
  GET /api/stocks/search?q=삼성
  ```
- `stock` 테이블(`symbol` · `name` · `market`)에 32개 종목이 들어 있다.
- 결과를 눌러도 화면 전환은 없다 (목록만 닫힌다).

## 요구사항

`GET /api/stocks/search?q={검색어}`

- 응답: `[{ "symbol": "005930", "name": "삼성전자", "market": "KOSPI" }, ...]`
- 검색어는 앞뒤 공백을 제거하고 쓴다
- **종목코드 또는 종목명**에 검색어가 들어 있으면 결과에 포함한다 (부분 일치)
- 영문은 **대소문자를 구분하지 않는다** (`tsla` → 테슬라)
- `%` · `_` 는 와일드카드가 아니라 **글자 그대로** 찾는다 (`%` → 빈 목록)
- 정렬: 종목명 오름차순 · **최대 10건**
- 검색어가 없거나 공백뿐이면 **400**
- 결과가 없으면 200 과 빈 목록

## 지켜야 할 것

- Controller → Service → Mapper 계층을 지킨다
- SQL 은 Mapper XML 에 둔다
- `StockController` · `MovingAverageService` 는 건드리지 않는다 — 검색은 별도 Controller · Service · Mapper 로 만든다

## 완료 기준

1. `./gradlew test` 가 통과한다 (기존 테스트 포함)
2. 위 요구사항의 각 줄을 검증하는 테스트가 있다
3. `scripts/start.*` 로 띄운 화면의 검색창에 입력하면 결과 목록이 뜬다

## 확인용 예시 (시드 데이터 기준)

| 검색어 | 기대 결과 |
|---|---|
| `삼성` | 4개 — 삼성SDI · 삼성물산 · 삼성바이오로직스 · 삼성전자 순 |
| `tsla` | 테슬라 (TSLA · NASDAQ) |
| ` sox ` (앞뒤 공백) | SOXL · SOXS |
| `0` | 10개 (11개 이상 일치 → 최대 10건) |
| `%` · `_` | 빈 목록 |
| `없는종목` | 빈 목록 |
| (공백만) · (q 없음) | 400 |
