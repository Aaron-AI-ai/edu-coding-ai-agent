# 수업 전 수강생 수준 확인 설문

수업 전에 현재 경험과 이해 수준을 확인하기 위한 설문입니다. 정답이 없으니 **가장 가까운 항목 하나**를 편하게 골라 주세요. (소요 시간 약 3분)

---

## Q1. Claude Code, Cursor, Copilot 같은 AI 코딩 도구를 얼마나 사용해 보셨나요?

1. 들어본 적도 없다
2. 들어봤지만 써 본 적은 없다
3. 몇 번 가볍게 써 봤다
4. 업무나 개인 프로젝트에서 가끔 쓴다
5. 거의 매일 쓴다

## Q2. Claude Code(터미널 기반 코딩 에이전트)를 사용해 본 경험은?

1. 처음 들어본다
2. 이름만 안다
3. 설치만 해 봤다
4. 간단한 작업을 시켜 본 적 있다
5. 실제 프로젝트에서 꾸준히 쓰고 있다

## Q3. ChatGPT·Claude 같은 챗봇과 "에이전트"의 차이를 어느 정도 설명할 수 있나요?

1. 차이를 모른다
2. 같은 것 같다
3. 에이전트가 더 똑똑한 챗봇 정도로 안다
4. 에이전트는 도구를 쓰며 스스로 여러 단계를 수행한다는 것을 안다
5. 도구 호출, 루프, 컨텍스트 관리 구조까지 설명할 수 있다

## Q4. LLM(대규모 언어 모델)이 동작하는 방식에 대한 이해는?

1. 전혀 모른다
2. "AI가 알아서 답한다" 정도로 안다
3. 학습한 데이터로 다음 단어를 예측한다는 것을 안다
4. 토큰, 컨텍스트 윈도우, 환각(hallucination) 개념을 안다
5. 위 개념에 더해 모델별 특성과 한계를 비교·설명할 수 있다

## Q5. 프롬프트 작성 경험은?

1. 해 본 적 없다
2. 질문을 짧게 던지는 정도다
3. 역할·맥락·형식을 넣어 쓰려고 노력한다
4. 예시 제공, 단계별 지시 등 기법을 의식하며 쓴다
5. 팀이나 업무에서 재사용하는 프롬프트 템플릿을 만들어 쓴다

## Q6. `CLAUDE.md`, MCP, 서브에이전트, 스킬(Skill), 훅(Hook) 중 알고 있거나 써 본 것은?

1. 모두 처음 듣는다
2. 이름만 들어봤다
3. 1~2개 개념을 안다
4. 3개 이상 알고 일부는 직접 설정해 봤다
5. 대부분 직접 구성해 실무에 적용했다

## Q7. AI가 생성한 코드를 어떻게 검증하나요?

1. AI 코드를 써 본 적 없다
2. 대부분 그대로 사용한다
3. 실행해 보고 동작하면 쓴다
4. 코드를 읽고 테스트를 돌려 확인한다
5. 테스트·리뷰·린트 등 검증 절차를 정해 두고 따른다

## Q8. 터미널(CLI)과 Git 사용에 얼마나 익숙하신가요?

1. 터미널을 거의 열어본 적 없다
2. `cd`, `ls` 정도만 쓴다
3. 기본 명령어와 `git add/commit/push`는 쓸 수 있다
4. 브랜치, 머지, 충돌 해결까지 다룬다
5. 스크립트 작성과 Git 워크플로를 자유롭게 다룬다

## Q9. AI 코딩 도구를 업무에 쓸 때 보안·정보 보호(소스코드·민감정보 입력 등)를 어떻게 고려하시나요?

1. AI 도구를 써 본 적이 없어 고려해 본 적이 없다
2. 별다른 고려 없이 쓴다
3. 비밀번호·개인정보 같은 민감한 정보는 넣지 않으려고 주의한다
4. 회사의 AI 사용 정책을 알고, 코드·데이터를 외부로 보내도 되는지 구분해서 쓴다
5. 권한 설정·샌드박스 같은 기술적 통제를 직접 구성하거나 팀 정책으로 만들어 적용한다

## Q10. 이번 교육에서 가장 기대하는 것은?

1. AI 코딩 도구가 무엇인지 기초부터 알고 싶다
2. 도구 설치와 기본 사용법을 익히고 싶다
3. 업무에 바로 쓸 수 있는 활용 패턴을 배우고 싶다
4. 에이전트 설정(CLAUDE.md·MCP·스킬 등)을 고도화하고 싶다
5. 팀 단위 도입과 AI 기반 개발 프로세스(AI-SDLC)를 설계하고 싶다

| 평균 | 수준 | 수업 운영 제안 |
|------|------|----------------|
| 1.0 ~ 2.0 | 입문 | 개념·용어 설명과 설치 실습에 시간을 더 배분 |
| 2.1 ~ 3.5 | 초·중급 | 기본 흐름은 빠르게, 하네스 설정·검증 실습에 집중 |
| 3.6 ~ 5.0 | 중·상급 | 고급 설정과 워크플로 설계 중심으로 심화 진행 |
