# 한 장 요약

> **같은 도구, 다른 결과**
> AI Agent 기반 SW 개발의 비법 — 나만 몰랐던 이야기

## 학습 목표

1. AI Agent 시대에 SW 개발자가 갖춰야 할 필수 요소를 이해한다
2. 차세대 금융 시스템에서 많이 활용하는 Spring Boot·Java 기반 미니 프로젝트를 AI Agent로 직접 개발해 본다

## 개발자가 알아야 할 필수 요소 6가지

| # | 요소 | 한 줄 설명 |
|---|---|---|
| 01 | 필수 플러그인 & MCP | 업무에 실제로 쓸 도구만 골라 연결하는 법 |
| 02 | Skill, Rule 설계 | 필요할 때만 불려오는 지식과 지켜야 할 규칙을 설계하기 |
| 03 | 하네스 | Skill·Rule·Subagent를 하나로 묶어 AI가 정해진 대로 일하게 만드는 틀 |
| 04 | Loop 엔지니어링 | 계획 → 실행 → 검증을 스스로 도는 루프로 설계 |
| 05 | Graph 엔지니어링 | 노드 분리·컨텍스트 격리·병렬 실행으로 확장 |
| 06 | AI-SDLC | 명세부터 릴리즈까지, 사람의 역할이 바뀐 개발 생애주기 |

## 실습 프로젝트

차세대 **Spring Boot·Java** 기반 미니 금융 서비스(주식 차트 웹)를 **AI Agent로 직접 구현**하며 하네스·루프를 몸에 익힙니다.

## Day 1 / Day 2 한눈에 보기

| Day 1 — 하네스 구성과 첫 기능 개발 | Day 2 — 루프·그래프 엔지니어링과 AI-SDLC |
|---|---|
| 코딩 관련 모델 트렌드 파악 및 벤치마크(Bench) 정보 알아보기 | 루프·그래프 엔지니어링 개념과 실습 |

| 내 하네스 직접 구성 + 조회 API 개발 | 실습 및 Q&A |
