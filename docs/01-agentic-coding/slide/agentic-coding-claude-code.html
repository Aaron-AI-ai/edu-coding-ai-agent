MCP — AI 에이전트를 시스템에 꽂는 표준 연결

클릭하면 확대
노트북 = AI 앱(Host) · 허브 = MCP · 케이블 = MCP Server · 끝에 꽂힌 것 = 원격 서비스 · 로컬 데이터
MCP(Model Context Protocol) 는 AI 에이전트가 외부 시스템과 이야기하는 표준 규격이다. USB-C 처럼 한 번 맞춰 두면 어떤 AI 앱에서도 같은 연결을 쓴다.
HostAI 앱 — Claude Code · Claude Desktop · IDE. 사용자가 대화하는 곳
ClientHost 안에서 서버 하나와 1 : 1 로 연결을 맡는 부분
Server기능을 내놓는 쪽 — 도구 · 리소스 · 프롬프트. 로컬(파일 · DB) 또는 원격(Slack · Gmail · Calendar)
연결하면 에이전트가 더 할 수 있는 것
읽기사내 DB · 문서 · 최신 라이브러리 문서 (context7)
실행티켓 생성 · 메시지 전송 · 일정 등록
검증브라우저를 직접 열어 화면 확인 (Playwright)
재사용서버 하나를 여러 AI 앱 · 팀원이 같이 쓴다
Skill 은 아는 것을, MCP 는 할 수 있는 것을 늘린다. context7 도 MCP Server 다 — 뒤에서 직접 연결해 본다.

Hooks — 정해진 순간에 반드시 실행된다

클릭하면 확대
Hook 은 에이전트가 일하는 흐름의 정해진 시점(세션 시작 · 도구 실행 전후 · 작업 끝)마다 자동으로 실행되는 명령이다. CLAUDE.md 의 지시는 AI 가 잊을 수 있지만, hook 은 매번 반드시 돈다.
개발 흐름의 어느 단계에 붙이나
작업 시작환경 준비 — 브랜치 · 이슈 · 팀 규칙을 미리 알려 준다
요청 입력입력 점검 — 비밀번호 · 키 · 고객 정보가 섞였는지 본다
코드 수정 전안전장치 — 위험 명령 · 운영 설정 · .env 수정을 막는다
코드 수정 후품질 자동화 — 포맷터 · import 정리를 바로 적용한다
작업 마무리검증 게이트 — 린트 · 테스트 · 빌드를 못 넘으면 다시 고치게 한다
대기 중알림 — 승인 · 입력을 기다리면 메신저 · 데스크톱으로 알린다
이런 일이면 hook 으로 만든다
매번 빠뜨리는 일린트 · 포맷 · 테스트 실행
사람이 보기 귀찮은 일비밀 정보 · 금지 파일 검사
사고 나면 큰 일운영 DB · 삭제 명령 차단
CLAUDE.md 는 부탁, Hook 은 보장이다. 꼭 실행돼야 하는 것만 hook 으로 — 느린 명령은 매 턴을 느리게 만든다. 시점 전체는 다음 장.
